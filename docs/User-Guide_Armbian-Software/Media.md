# Media servers, organizers and editors


Install and configure these applications through [`armbian-config`](/armbian-config/) or from the pages below:

- [Emby](/software/emby/) — Emby organizes video, music, live TV, and photos
- [Filebrowser](/software/filebrowser/) — Filebrowser provides a web-based file manager accessible via a browser
- [Hastebin](/software/hastebin/) — Hastebin Paste Server
- [Immich](/software/immich/) — Immich - high-performance self-hosted photo and video backup solution
- [Jellyfin](/software/jellyfin/) — Jellyfin Media System
- [Navidrome](/software/navidrome/) — Navidrome music server and streamer compatible with Subsonic/Airsonic
- [Nextcloud](/software/nextcloud/) — Nextcloud content collaboration platform
- [OMV](/software/omv/) — Deploy NAS using OpenMediaVault
- [Owncloud](/software/owncloud/) — Owncloud share files and folders, easy and secure
- [Syncthing](/software/syncthing/) — Syncthing continuous file synchronization
- [Stirling](/software/stirling/) — Stirling PDF tools for viewing and editing PDF files
