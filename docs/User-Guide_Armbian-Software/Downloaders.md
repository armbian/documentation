# Download apps for movies, TV shows, music and subtitles


Install and configure these applications through [`armbian-config`](/armbian-config/) or from the pages below:

- [Bazarr](/software/bazarr/) — Bazarr automatic subtitles downloader for Sonarr and Radarr
- [Deluge](/software/deluge/) — Deluge BitTorrent client
- [qBittorrent](/software/qbittorrent/) — qBittorrent BitTorrent client
- [Prowlarr](/software/prowlarr/) — Prowlarr index manager and proxy for PVR
- [Jellyseerr](/software/jellyseerr/) — Jellyseerr Jellyfin/Emby/Plex integration install
- [Lidarr](/software/lidarr/) — Lidarr automatic music downloader
- [Medusa](/software/medusa/) — Medusa automatic downloader for TV shows
- [Radarr](/software/radarr/) — Radarr automatic downloader for movies
- [SABnzbd](/software/sabnzbd/) — SABnzbd newsgroup downloader
- [Sonarr](/software/sonarr/) — Sonarr automatic downloader for TV shows
- [Transmission](/software/transmission/) — Transmission BitTorrent client
